# 🎄 Advent CV — Интерактивное портфолио-календарь

Необычный формат самопрезентации, созданный чтобы пробить «баннерную слепоту» при поиске работы и превратить знакомство с кандидатом в интерактивный опыт.

Вместо скучного PDF на несколько страниц — сетка из 31 ячейки с геометрическим орнаментом, где за каждым днём скрывается кейс, рабочий принцип, стек навыков или личная история.

---

## ✨ Ключевые фичи

* **Два сценария использования (Переключатель в подвале):**
  * **Режим «По датам»:** для друзей, подписчиков и соцсетей — ячейки открываются последовательно от заданной даты старта (`startDate`), создавая эффект ежедневного адвент-календаря.
  * **Режим «Открыты все»:** для рекрутеров и нанимающих менеджеров — разблокирует все 31 карточку в один клик, если нет времени ждать.
* **Отделение контента от кода (`content.js`):** Вся информация (имя, роль, навыки, контакты, дата старта и тексты всех 31 ячеек) вынесена в отдельный конфигурационный файл. Сайт можно легко пересобрать под любую вакансию без правки вёрстки.
* **Zero-Backend & Zero-Dependencies:** Чистый HTML, CSS и Vanilla JS. Работает локально с диска и мгновенно разворачивается на GitHub Pages без сборки и серверов.
* **Сохранение прогресса:** Открытые карточки запоминаются в `localStorage` браузера.

---

## 🗂 Структура проекта

```text
├── index.html      # Каркас страницы, SVG-орнамент и логика работы календаря
├── content.js      # Пульт управления: профиль, настройки дат и 31 карточка
└── README.md       # Описание проекта
```

---

## 🚀 Как запустить или адаптировать под себя

1. Склонируйте репозиторий или скачайте файлы `index.html` и `content.js`.
2. Откройте `content.js` и замените данные в блоках `settings`, `profile` и `days` на свои.
3. Откройте `index.html` в любом браузере или включите **GitHub Pages** в настройках репозитория (`Settings -> Pages -> Branch: main`), чтобы получить публичную ссылку для резюме.
